API Reference

Stream-proxy and Chromecast control API for the Unofficial Kick App.

Base URL: http://<host>:8081

Stream endpoints return a { status, message, data } envelope
Response envelope. All /streams/* endpoints return JSON shaped as { "status": "success" | "error", "message": "", "data": … }. On error, status is "error", message carries the reason, and the HTTP status reflects the failure (400 invalid input, 404 not found, 503 upstream unavailable). Slugs must match ^[a-zA-Z0-9_-]{1,255}$.

System

GET/health

Per-component health (cache + circuit breakers). Returns 503 if any component is unhealthy, otherwise 200.

200 response
{
  "status": "healthy",
  "uptime_seconds": 1432,
  "components": {
    "cache": { "status": "healthy", "size": 84, "max_size": 2000, "utilization_pct": 4.2 },
    "circuit_breakers": {
      "critical":     { "status": "healthy", "state": "closed" },
      "non_critical": { "status": "healthy", "state": "closed" }
    }
  }
}
GET/health/live

Minimal liveness probe (used by the container healthcheck).

200 response
{ "status": "ok" }
GET/metrics

Cache, upstream call count, circuit-breaker stats per lane, and in-flight dedup metrics.

200 response (excerpt)
{
  "cache": { "size": 84, "max_size": 2000, "hit_count": 9201, "miss_count": 312 },
  "upstream": {
    "call_count": 514,
    "circuit_breakers": { "critical": {…}, "non_critical": {…} },
    "circuit_breaker_events": { "critical": { "rejections": 0, "failures": 1 }, … }
  },
  "inflight": { "active_keys": 0, "timeout_count": 3 },
  "uptime_seconds": 1432
}
GET/config/languages

Featured-content languages and the default code.

200 response
{
  "languages": [ { "code": "en", "name": "English" }, { "code": "tr", "name": "Turkish" }, … ],
  "default_language": "tr"
}

Streams

GET/streams/featured-livestreams

Featured livestreams for a language, with optional category filtering. Served stale-while-revalidate (instant from cache, refreshed in the background).

Query parameters
NameTypeNotes
languagestringoptionalLanguage code (default en); falls back to the default if invalid.
pageintoptionalPage number, ≥ 1 (default 1).
categorystringoptionalCategory slug. Switches to the filtered livestreams source.
subcategory / subcategoriesstringoptionalFurther category filtering.
sortstringoptionalOne of asc, desc, featured.
strictbooloptionaltrue to apply strict category matching.
200 response
{ "status": "success", "message": "", "data": [ { "channel": {…}, "is_live": true, "viewer_count": 7531, … } ] }
GET/streams/play/{slug}

Channel play state and metadata. Stale-while-revalidate; 404s are negatively cached briefly.

200 response (live)
{
  "status": "success", "message": "",
  "data": {
    "status": "live",
    "channel_slug": "jahrein",
    "username": "Jahrein",
    "profile_picture": "https://…",
    "playback_url": "/streams/m3u8/jahrein.m3u8",
    "livestream_id": 12345678,
    "livestream_title": "…",
    "livestream_viewer_count": 7531,
    "livestream_category": "Just Chatting",
    "livestream_thumbnail_url": "https://…"
  }
}
When offline
{ "status": "success", "message": "", "data": { "status": "offline", "channel_slug": "jahrein", … } }
GET/streams/m3u8/{file}

HLS master playlist proxy. {file} is {slug}.m3u8. Returns the rewritten application/vnd.apple.mpegurl playlist for direct playback.

Example
GET /streams/m3u8/jahrein.m3u8  →  #EXTM3U … (HLS playlist)
GET/streams/go/{slug}

307 redirect to /streams/m3u8/{slug}.m3u8 — a convenience entry point for external players.

GET/streams/search

Channel search via Kick's Typesense cluster. Avatars are enriched server-side from cache when available.

Query parameters
NameTypeNotes
qstringrequiredSearch query, 2–100 characters.
200 response
{ "status": "success", "message": "",
  "data": [ { "slug": "jahrein", "username": "Jahrein", "followers_count": 1200000,
              "is_live": true, "verified": true, "profile_picture": "https://…" } ] }
GET/streams/avatar/{slug}

Channel profile picture. Reuses a cached play response when present, otherwise fetches the channel. 7-day cache TTL.

200 response
{ "status": "success", "message": "", "data": { "profile_picture": "https://…" } }
GET/streams/clips/{slug}

Normalized clip list for a channel.

200 response
{ "status": "success", "message": "", "data": { "clips": [ { "id": "…", "title": "…", "thumbnail_url": "…", "duration": 42, … } ] } }
GET/streams/vods/{slug}

Past-broadcast (VOD) list for a channel.

200 response
{ "status": "success", "message": "", "data": { "vods": [ { "id": …, "title": "…", "duration": …, … } ] } }
GET/streams/vods/{slug}/{vodID}

Playback details for a single VOD. Returns 404 if the VOD is not found.

GET/streams/viewers

Live viewer count for one livestream.

Query parameters
NameTypeNotes
idintrequiredLivestream ID (> 0).
200 response
{ "status": "success", "message": "", "data": { "viewer_count": 7531 } }
GET/streams/viewers/batch

Viewer counts for many livestreams in one call. IDs are chunked and fetched in parallel upstream.

Query parameters
NameTypeNotes
idsstringrequiredComma-separated livestream IDs, max 50 (excess is truncated).
200 response
{ "status": "success", "message": "", "data": { "12345678": 7531, "23456789": 412 } }

Chromecast

GET/api/chromecast/devices

List discovered Cast devices. Triggers a background scan when forced or when known hosts are supplied.

Query parameters
NameTypeNotes
forcebooloptionaltrue to bypass the device-cache TTL and rescan.
known_hostsstringoptionalComma/space-separated hostnames or IPs to probe directly.
200 response
{ "status": "success", "message": "",
  "data": { "devices": [ { "name": "Living Room", "uuid": "…" } ], "scanning": true } }
POST/api/chromecast/select

Connect to a device by UUID. Waits for any in-flight scan to finish first. 409 if a scan or another selection is in progress, 404 if not found / connect failed.

Request body
{ "uuid": "device-uuid" }
POST/api/chromecast/cast

Load an HLS stream on the selected device. Retries once if the receiver is waking from standby.

Request body
{ "stream_url": "http://…/jahrein.m3u8", "title": "Kick Stream" }
POST/api/chromecast/stop

Stop playback and disconnect. Optional uuid guards against stopping a different device.

Request body (optional)
{ "uuid": "device-uuid" }
GET/api/chromecast/last-device

The last successfully selected device, or null.

200 response
{ "status": "success", "message": "", "data": { "device": { "uuid": "…", "name": "Living Room" } } }
GET/api/chromecast/status

Current playback status snapshot.

200 response
{ "status": "success", "message": "",
  "data": { "status": "connected", "device_name": "Living Room", "is_playing": true,
            "volume_level": 0.6, "duration": 0, "current_time": 0 } }
GET/api/chromecast/status/stream

Server-Sent Events stream of status updates (text/event-stream). One shared poller drives all subscribers; control actions push an immediate update.

Event payload
data: { "status": "success", "message": "", "data": { "status": "connected", … } }
POST/api/chromecast/pause

Pause playback on the active device. No body.

POST/api/chromecast/play

Resume playback on the active device. No body.

POST/api/chromecast/volume

Set the device volume.

Request body
{ "level": 0.6 }   // 0.0 – 1.0
POST/api/chromecast/seek

Seek to an absolute position (seconds) in the current media.

Request body
{ "position": 120 }   // seconds, ≥ 0
For deeper notes on the upstream Kick endpoints this proxy wraps, see KICK_PUBLIC_API.md in the repository.
